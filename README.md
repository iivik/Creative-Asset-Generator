# Creative Asset Generator 🎨

An AI-powered tool that generates shareable, real-world-usable creative assets — social posts, banners, carousels, and visual content — built for marketers and content creators who want output they can actually use.

**Live on Google AI Studio:** [Open app](https://ai.studio/apps/6efad8ae-ac8b-4986-bbeb-e0f6a722adca)

## What it does
- Generates social-ready creative assets from a prompt
- Outputs formats suited for LinkedIn, Instagram, and presentations
- Designed for virality — not just aesthetics

## Built with
- TypeScript / Vite
- Google Gemini API (via AI Studio)
- Deployed via Google AI Studio

## Run locally
**Prerequisites:** Node.js
```bash
npm install
# Add your GEMINI_API_KEY to .env.local
npm run dev
```

## Background
Experiment in using generative AI for GTM content workflows. Built to test whether AI can produce brand-consistent assets at speed without a design team.
